# Public Paradigm Governance Charter

**English** | [简体中文](GOVERNANCE.zh-CN.md)

## Core Position

This project is not a private tool, but a **public generative web interaction paradigm infrastructure**. The natural language local webpage reconstruction paradigm belongs to all public users, and all core mechanisms are permanently open, transparent, and publicly supervisable.

## 1. Paradigm Invariant (Unchangeable Baseline)

No official version, community iteration, or derivative fork is allowed to delete, weaken, or bypass the following public baseline mechanisms:

1. Default security lockdown: forbid arbitrary AI-generated JavaScript execution; only CSS modification enabled by default.
2. Dangerous capability must be user-initiated with prominent risk disclosure.
3. Automatic sensitive DOM desensitization before AI transmission.
4. Zero silent privacy collection, zero background data stealth upload.
5. User private keys are fully local-only; no server-side collection.

## 2. Public Supervision Mechanism

1. All core security logic changes require public proposal + public review.
2. Security-related code modifications must be explicitly marked in [CHANGELOG.md](CHANGELOG.md).
3. Any user or security researcher can submit audit reports and risk issues via GitHub Issues.
4. Malicious forks that break the public baseline will be publicly identified and excluded from community paradigm compatibility certification.

## 3. Contribution & Review Rules

1. Ordinary feature optimization: loose community review.
2. Security baseline / data flow / risk control modification: mandatory dual review by at least two maintainers.
3. All contributions follow the [Developer Certificate of Origin (DCO)](https://developercertificate.org/) to ensure copyright legality.

See [CONTRIBUTING.md](CONTRIBUTING.md) for details.

## 4. Compatibility Definition

Only derivatives that fully comply with this charter + GPLv3 Public Paradigm Supervision Additional Terms are recognized as compatible implementations of this public paradigm. Privatized, stripped, and closed-source modified versions are not recognized.

## 5. Permanent Public Attribute

This paradigm's public attribute is permanent and irreversible. It shall never be privately monopolized, commercially encapsulated, or closed-sold by any individual or organization.
