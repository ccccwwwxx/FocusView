# Public Paradigm Governance Charter
## 公共生成式Web交互范式 公众监管治理章程

### Core Position / 核心定位

This project is not a private tool, but a **public generative web interaction paradigm infrastructure**.
The natural language local webpage reconstruction paradigm belongs to all public users,
and all core mechanisms are permanently open, transparent, and publicly supervisable.

本项目不是私有工具，而是**公共生成式Web交互范式基础设施**。
自然语言本地网页重构范式属于全体公众用户，
所有核心机制永久开放、透明、接受公众监管。

---

### 1. Paradigm Invariant / 范式不变量（不可更改基线）

No official version, community iteration, or derivative fork is allowed to delete, weaken,
or bypass the following public baseline mechanisms:

任何官方版本、社区迭代或衍生分叉，均不得删除、弱化或绕过以下公共基线机制：

1. Default security lockdown: forbid arbitrary AI-generated JavaScript execution; only CSS modification enabled by default.
   默认安全锁定：禁止任意AI生成JS执行，默认仅允许CSS修改。
2. Dangerous capability must be user-initiated with prominent risk disclosure.
   危险能力必须由用户主动开启，并附带显著风险告知。
3. Automatic sensitive DOM desensitization before AI transmission.
   DOM提交AI前自动执行敏感数据脱敏。
4. Zero silent privacy collection, zero background data stealth upload.
   零静默隐私收集，零后台数据偷传。
5. User private keys are fully local-only; no server-side collection.
   用户密钥完全本地存储，服务端不收集。

---

### 2. Public Supervision Mechanism / 公众监管机制

1. All core security logic changes require public proposal + public review.
   所有核心安全逻辑变更须公开提案 + 公开评审。
2. Security-related code modifications must be explicitly marked in CHANGELOG.
   安全相关代码修改必须在CHANGELOG中显式标注。
3. Any user or security researcher can submit audit reports and risk issues via GitHub Issues.
   任何用户或安全研究者可通过GitHub Issues提交审计报告和风险问题。
4. Malicious forks that break the public baseline will be publicly identified
   and excluded from community paradigm compatibility certification.
   破坏公共基线的恶意分叉将被公开标识，并排除出社区范式兼容认证。

---

### 3. Contribution & Review Rules / 贡献与评审规则

1. Ordinary feature optimization: loose community review.
   普通功能优化：宽松社区评审。
2. Security baseline / data flow / risk control modification: mandatory dual review by at least two maintainers.
   安全基线/数据流/风控修改：强制至少两名维护者双重评审。
3. All contributions follow the [Developer Certificate of Origin (DCO)](https://developercertificate.org/)
   to ensure copyright legality.
   所有贡献遵循DCO（开发者来源证书），确保版权合法性。

---

### 4. Compatibility Definition / 兼容性定义

Only derivatives that fully comply with this charter + GPLv3 Public Paradigm Supervision Additional Terms
are recognized as compatible implementations of this public paradigm.
Privatized, stripped, and closed-source modified versions are not recognized.

只有完全遵守本章程 + GPLv3公共范式监管附加条款的衍生作品，
才被承认为本公共范式的兼容实现。
私有化、阉割、闭源修改版本不予承认。

---

### 5. Permanent Public Attribute / 永久公共属性

This paradigm's public attribute is permanent and irreversible.
It shall never be privately monopolized, commercially encapsulated,
or closed-sold by any individual or organization.

本范式的公共属性是永久且不可撤销的。
任何个人或组织不得将其私有垄断、商业封装或闭源售卖。
